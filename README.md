# Forgewright

Forgewright 是一条 AI 辅助的分支叙事内容生产流水线：运行时是极薄的 JSON 对话图播放器（无 LLM），所有生成与校验在开发期完成。

## 当前阶段

**阶段 0：基座搭建**。目标是在无 LLM 参与下搭起 Schema、播放器、状态总线与一个手写测试场景。尚未进入阶段 1（单节点 AI 生成），因此本仓库暂不包含任何 LLM 调用、prompt 模板或生成代码。
