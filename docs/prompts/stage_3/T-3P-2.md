## B. 对齐 + 合并

3. 加载锁定骨架（**一律经 T-3P-0 的 `promptpack/io.py::load_design_artifact` 读**，禁止自写解析——critique F-3；loader 返回内层 design dict：topology / skeletons / beats_plan / **run_config**——图级字段 graph_id / scene_anchor / speaker_ref / character_refs 全部从 run_config 读；**不另收配置参数**）→ 全键精确对齐：

   - choice 选项序号 1..N 连续完整、N = 锁定选项数（E4）
   - beats 每拍 continue 必有、end 无 options/continue（E5 / E6）
4. 对齐全过 → 确定性合并：复用 assemble 机械语义（_mk_option / target_map / route_to 接线 / beats 链 `{pid}_b{i}` 串接 / `_normalize_line` 引号归一 / `_dialogue_entries` 图级单说话人）→ scene.json：
   - `schema_version="0.1.1"`（不 bump；ADR-040 兼容路径）
   - ADR-040 不变量：narration=纯旁白、`dialogue=[{speaker_ref,line}]`、节点级 `speaker_ref=None`
   - **node + option 级 `generation_trace.source="human"`**（正文来源审计）
5. 确定性：同 reply + 同 design.json（含 run_config）→ 逐字节相同 scene.json。
