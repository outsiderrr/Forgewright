# 如实边界说明（写进 E2E 报告，不许夸大）

路线 A 下编剧只能填正文（narration / dialogue 行 / options 文本），**触不到**结构字段——所以三层校验 + 机械预检对"纯正文错误"基本恒 pass（speaker_ref 由 run_config 锁定、condition/effects 由代码填、monotonic 对 human 豁免）。**验收闸守的是结构完整性与本体一致性（防管线 bug / 防绕过 P-B 手改 scene.json / 防配置错误），对编剧手笔的把关主要在格式层 E1-E8 + AP 记录**。这是路线 A 锁结构的设计后果，不是缺陷；E2E 报告必须如实写明这一分工，不得把验收闸描述成"能拦编剧写坏的文字"。

# 待落地点

## A. 验收管线（`/generator/promptpack/acceptance.py` 新建 + ingest CLI 接线）
