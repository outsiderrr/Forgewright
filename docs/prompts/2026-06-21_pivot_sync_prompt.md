## 【同步正文】（粘这段）

Forgewright 于 2026-06-21 发生一次**项目级战略转向**，已立 **ADR-039（写作提示词包转向）**。请据此更新你的工作前提：

**一句话**：本仓库**不再用 LLM 自建对白正文生成**。产出从"AI 生成的正文"改为"**每场景一份写作提示词包**（结构锁定 + 格式契约 + 文风指南 + 跨场景连续性摘要）+ **回流验收**"。正文由游戏制作人雇的**编剧用自己选的模型（BYOM, bring your own model）**写、人工润色后回流进引擎。**文字质量由编剧负责；我们负责可玩结构 + 格式契约 + 回流校验 + 本体一致性守门。**

**为什么转**：正文质感/文风（Phase 2）卡了几个月未达"作者少改即可用"。作者判断：① 国内模型中文创作已够用，不必自建管线追模型质量；② 真实生产会雇编剧，编剧已有成熟 AI 写作工作流；③ 作者本人不具备"用 AI 创作"的能力，自建正文生成是能力错配。结论：把"正文怎么生成、文字好不好"整环交给编剧，我们做上游真正擅长的——把"可玩场景结构"压成"写作提示词包"，并在回流时把住格式与一致性的闸。

**核心机制（路线 A）**：我们**锁结构**（node_id / 分支去向 / 线索分层 / 检定 / 状态效果），编剧**只填正文**（旁白 / NPC 对白 / 选项台词）。填空单位 = **整个场景**；回流按 node_id + 显式选项序号**确定性合并**、key 对不上即**硬报错**退回编剧。这把 ADR-008"LLM 不能直接写状态"推到极致——LLM（编剧的工具）彻底在系统外，连结构槽都不碰。

**首版范围（作者收窄）**：只做 **P-A 写作提示词渲染器 + P-B 回流合并与验收落地**的最小闭环；跨场景连续性先用现成 `prior_scene_summaries` + 一行 NPC 状态摘要的**便宜版**。**P-C（幕级打包 / 手动 loop）、P-D（费工连续性：NPC 跨场景状态增量 + 台词 callback）、P-E（文风资产重打包）推到核心闭环验证后或有真实编剧反馈再做**。

**被取代 / 改角色的**：① Pass 2 正文引擎**退役为生成路径**；② 文风资产（role_rules 三契约 / 反 AI 腔规则 / 14 维 taxonomy / 锚点库 A1–A18）**重打包**为编剧提示词包内容 + 可选 judge QA（不删）；③ ADR-030 审美 schema 的"prompt-hook 生成控制"用途退役（偏好档作编剧指南内容 survives）；④ 结构层（ADR-038 分拍节点图、多 pass、动态拓扑、组装、校验器）**全部保留**——beats 拆拍从"LLM 涌现"改为"Pass 1 确定性产物"。

**诚实边界（别夸大）**：LLM **未**移出系统——结构引擎 Pass 1、跨场景摘要、可选 judge 仍用 LLM，仍受中转站超时/模型质量约束。真赌注：**结构值得自建（工程杠杆 + 可确定性校验）；正文不值得自建（手艺 + 主观 + 模型换代 + 作者做不了）**。

**硬约束不变**：运行时永远无 LLM；只在 `/generator` + `/tools` 施工；`/validator` 只读复用；**默认不动 `/schema`**（场景编号若需持久化字段 = 硬地基，停下单独走作者批准的 schema-only ABC）；结构层逻辑不动。

## 【附加 · 给施工 / L3 工程会话】（如对象是写代码的会话，加粘这段）

首版只做两件，均在 `/generator`（+ 必要的 `/tools`）：
- **P-A 写作提示词渲染器**：复用 Pass 1 结构引擎产出的场景骨架（contract/topology/skeleton）+ 新增**确定性拆拍器**（把 beats plan 节点展平成锁定 micro-node，每拍带 reveal 子集 + continue 占位）→ 渲染成**整场景**写作提示词（结构槽 + 格式契约【role_rules 三契约 + 8 条普适 AP + 白描预设 + 人称约定 D + continue 口语规则】+ 文风锚点 few-shot【`generator/prompts/style/anchors_v1.json`】+ 便宜版连续性摘要）。可借鉴 `generator/multipass/render.py` 的剧本式 markdown 渲染。
- **P-B 回流合并器（新模块，不是改 assemble.py）**：解析编剧填空（标签文本 / JSON）→ 按 node_id + 显式选项序号对齐锁定骨架 → 确定性填回（可复用 `assemble.py` 的 `_mk_option`/`target_map` 机械装配半，但对齐 + 容错那半要重写为**硬报错**）→ 过验收校验（复用 `validator/` 三层 + 机械预检，调用时 `generation_source="human"`）→ 落 `/content/` 可播放 scene.json。
不要：恢复 Pass 2 in-house 正文生成；动 `/schema`（要动先停下报作者）；动结构层拓扑/路由/承接逻辑。先 1 个场景端到端跑通（露西 spec 现成）再扩。
