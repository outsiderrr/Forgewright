### 3.1 [ERR] tools/review_ui/data.py:237 — `/api/review` 可写入不可审场景，且失败行会被记成 `schema_pass=True`

**问题**：`append_review()` 对 `_lookup_envelope()` 的结果不做存在性、`result.success`、mechanical pass 校验。任意 API caller 可以给不存在的 `scene_id`、`content/` 来源场景，或 batch 里的失败行写 review_log；失败/未知行还会走到 `schema_pass=True` 默认值。前端也只在 `source === "content"` 时禁用 A/R，失败 batch 行仍可被作者点 `[A]`。

**为什么是 CRITICAL**：ADR-020 / Stage 2 baseline protocol 锁定接受率分母来自进入 `scene_review_log.jsonl` 的作者标注；T-3.6a RUI-MVP-6 又要求 review_log 是唯一允许写入的元数据。这里会污染阶段 3 的真实接受率，属于生产期真相源错误。

**修复建议**：
```python
# 当前（问题代码片段）
env = self._lookup_envelope(scene_id, iter_id)
passes = _validator_passes(env or {})
record = {
    "schema_pass": passes["schema_pass"] if passes["schema_pass"] is not None else True,
    "accepted": decision == "accept",
}

# 建议
env = self._lookup_envelope(scene_id, iter_id)
if env is None:
    raise ValueError(f"scene is not reviewable from batch_dir: {scene_id}")
result = env.get("result") or {}
if result.get("success") is not True:
    raise ValueError(f"cannot review failed scene: {scene_id}")
passes = _validator_passes(env)
if passes["mechanical_pass"] is not True:
    raise ValueError(f"cannot review scene that failed mechanical pre-check: {scene_id}")

record = {
    "schema_pass": passes["schema_pass"] is True,
    "accepted": decision == "accept",
}
```

前端同样应按 `source === "batch" && !failure_reason && graph exists` 禁用/启用 A/R/S，不能只防 content 来源。

### 3.2 [ERR] tools/review_ui/api.py:38 — `[S] Skip` 没有进入持久化契约

**问题**：API 只接受 `Literal["accept", "reject"]`，data 层也只允许 accept/reject；前端点击 `[S]` 时直接 `nextScene()`，不 POST、不要求 reason、不写 `scene_review_log.jsonl`。同时 data 层的 review status 只有 accepted/rejected/unreviewed，若日志中已有 `accepted: null` 的显式 skip 行，会被误显示成 `[R] rejected`。

**为什么是 CRITICAL**：`docs/prompts/stage_3/T-3.6a.md` 明确要求 `/api/review` 写入 `[A]/[R]/[S] + reason + timestamp`，视图 4 的三按钮都应 POST；`generator/protocols/STAGE_2_BASELINE_PROTOCOL.md` §6 也规定进入 review_log 后 `[S]kip` 记入分母但不进分子。当前实现缺掉 MVP 核心按钮之一。

**修复建议**：
```python
# 当前（问题代码片段）
decision: Literal["accept", "reject"]

if decision not in ("accept", "reject"):
    raise ValueError(...)
"accepted": decision == "accept",
"reason": reason if decision == "reject" else None,

# 建议
decision: Literal["accept", "reject", "skip"]

if decision not in ("accept", "reject", "skip"):
    raise ValueError(...)
if decision in ("reject", "skip") and not (reason or "").strip():
    raise ValueError("reject/skip requires a reason")

"accepted": True if decision == "accept" else False if decision == "reject" else None,
"reason": reason if decision in ("reject", "skip") else None,
```

同时补齐 UI：`submitReview("skip")` 不应早退；`accepted is None` 要显示 `[S] skipped`，左侧 filter/status 也要有 skipped 态。

### 4.2 [SAFETY] tools/review_ui/data.py:200 — graph 文件读取未约束 `scene_id` 路径

**问题**：`get_graph_file()` 直接把 URL path param 拼进 `batch_dir / "graph_views" / scene_id / filename`。用 URL-encoded `..` 可越出单个 scene 目录；我用 TestClient 验证 `/api/graph/%2E%2E?format=mermaid` 会读取 `batch_dir/mermaid.mmd`（若存在）。

**为什么是 IMPORTANT**：这是标准路径遍历输入校验问题。虽然 review UI 默认 localhost、且 filename 被限制为三种固定文件名，但 CLI 允许改 `--host`，无 auth 工具不应依赖“前端不会这么请求”。

**修复建议**：
```python
# 当前（问题代码片段）
path = self.batch_dir / "graph_views" / scene_id / filename
if not path.exists():
    return None
return path.read_text(encoding="utf-8"), content_type

# 建议
base = (self.batch_dir / "graph_views").resolve()
view_dir = (base / scene_id).resolve()
if not view_dir.is_relative_to(base):
    return None
path = view_dir / filename
if not path.is_file():
    return None
return path.read_text(encoding="utf-8"), content_type
```

再加一个 API/data test：encoded `%2E%2E` 必须返回 404。

### 5.1 [DEPS] tools/review_ui/static/app.js:61 — CDN fallback 未钉到 `mermaid@10.9.1`

**修复建议**：
```javascript
// 当前
await loadScript('https://cdn.jsdelivr.net/npm/mermaid@10/dist/mermaid.min.js');

// 建议
await loadScript('https://cdn.jsdelivr.net/npm/mermaid@10.9.1/dist/mermaid.min.js');
```

顺手把 `vendor/README.md` 的“SHA pin”改成真实 SHA256 值会更稳。
