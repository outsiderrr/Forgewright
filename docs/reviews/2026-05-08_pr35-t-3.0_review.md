### 4.2 [ERR] generator/scene_experiment.py:153 — pre-flight probe 对所有 ProviderError 都退款，破坏现有预算三态语义

**问题**：`probe_provider_health()` 在任何 `ProviderError` 下都调用 `budget.refund_estimated()`。现有 `generate_node` / `scene_strategies` 的规则是：只有 request-not-sent 才退款；HTTP 4xx/5xx、非 JSON 响应等 request-sent failure 保留估算费用，避免 cost_log 低估真实花费。

**为什么是 IMPORTANT**：ADR-012 成本治理要求每个 LLM 调用可追踪。这个 probe 虽然便宜，但它新引入了与主生成路径不一致的账本语义，后续排查额度 / 账单差异时会制造假象。

**修复建议**：
```python
# 当前（问题代码片段）
except ProviderError as exc:
    if record_id is not None:
        budget.refund_estimated(
            record_id, reason=f"probe ProviderError: {exc}"
        )
    return False, f"ProviderError: {exc}"

# 建议
except ProviderError as exc:
    if record_id is not None and _is_request_not_sent(exc):
        budget.refund_estimated(record_id, reason="probe request_not_sent")
    return False, f"ProviderError: {exc}"
```
