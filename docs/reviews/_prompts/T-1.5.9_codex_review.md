# 本任务关键设计决策（不要当 bug 抓）

- **`estimate_cost` 硬编码取上限值（每张 $0.17, n × 0.17）是有意保守**。当前 OpenAI gpt-image-1 公开单价：low ≈ $0.011 / medium ≈ $0.042 / high ≈ $0.167（2026-05-01 采集）。本实现固定 high tier，避免类似 baseline_001 那种 0% 成功率烧钱事故；upstream image_budget 宁可超预留也不超扣。**不要建议**改成 size-aware 或 quality-aware 估算（推到后续 PR）。
- **`ref_images` 不上传字节，走 fallback 文本注入**（仅把 `Path` 列表追加到 prompt 文本里供模型/作者人工对照）。ADR-014 显式将"character reference upload (Strategy A)"推后到阶段 2；本任务**实现 fallback 模式**，不强制上传。**不要建议**在本任务实施真正的 binary upload。
- **`model_id` 默认 `"gpt-image-1"`**（ADR-014 决策）。**不要建议**默认改成 `dall-e-3` 或 `dall-e-2`。
- **provider 不做 budget / retry / 重试**——与 GeminiProvider 同源（ADR-011 / ADR-012）。budget 在主函数 `generate_character_sheet` 拦；retry 由调用方决定。**不要建议**在 OpenAIImageProvider 内加 retry 循环或 `image_budget.check()`。
- **错误一律包成 `ImageProviderError`**（catch `OpenAIError` 基类后 `raise ... from exc`）；原异常用 `__cause__` 链保留。**不要建议**让 OpenAI 原生异常逃逸到调用方——Protocol 契约要求 provider 自有异常类。
- **`image_bytes` 仅支持 `b64_json`**；URL 模式抛 `ImageProviderError` 提示扩展。gpt-image-1 默认返回 b64_json，下载 URL 需要额外的 httpx 依赖与流式落盘逻辑，本任务**不实现**。**不要建议**为未发生需求加 URL 下载分支（YAGNI）。
- **`raw_metadata` 含 `openai_response = response.model_dump(mode="json")`**——用于 trace + 未来对账。如果 SDK 响应 model_dump 失败（未来版本变形），降级写 `_response_type`，不让批处理崩盘。**不要建议**移除 model_dump 兜底。
- **`visual_parity_smoke` 是一次性脚本**，不联动 batch metrics。`run_parity_smoke()` 接受**已校验**的 prompt 列表（DI 友好），CLI 负责文件读 + 校验 + 切片。**不要建议**整合到 `experiment.py` / `metrics.py` 流水线。
- **parity smoke 的 graceful degradation 写在 `_build_default_api_provider`**：缺 `OPENAI_API_KEY` 返回 `(None, reason)`；调用方传 `api_provider=None` 时 per-pair 状态字段写 "skipped: no OPENAI_API_KEY"，**进程退出码 0**。**不要建议**改为非 0 退出（破坏 CI / 无 key dev 跑通）。
- **Manual provider rooted at `<pending_root>/parity/`** 是有意——避免与 T-1.5.7 image_import 扫描的 waystation 实战目录混合。**不要建议**改回 `<pending_root>/<asset_id>/`。
- **`prompt_id` 校验正则 `^[a-zA-Z0-9_]{1,64}$`**（用于 API 图像文件名；防止路径逃逸）。**不要建议**放宽为 schema 的 `^img_...` 正则（语义不同：`prompt_id` 是 smoke 输入侧 ID，不是 ImageAsset 的 asset_id）。
- **`_run_api_half` catch `Exception`** 兜 SDK shape 变更（`# pragma: no cover`）。专门 catch + log + 返回 partial fail。**不要建议**移除——一个 prompt 失败不该带垮整轮 smoke。

每条 finding 必须归到下列一类：

| 代号 | 类别 | 说明 |
|---|---|---|
| **ARCH** | 架构合规 | 是否违反 ADR / 模块边界 / 跨模块写入 |

| **TEST** | 测试 | 覆盖关键分支与失败路径；不冗余、不重言；mock 与真实分离；smoke 只在 `-m smoke` 跑 |

| **STYLE** | 风格 | 注释只解释 WHY 不解释 WHAT；命名清晰；项目约定遵守 |
| **OPEN** | 开源就绪度 | 作者 hard-code、公开接口稳定性、文档可移植性；OpenAI 单价硬编码的来源/日期/更新机制 |
