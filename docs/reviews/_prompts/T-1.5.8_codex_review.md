# 本任务关键设计决策（不要当 bug 抓）

- **视觉 AI 判官只辅助标红，不替代作者**——P1.4 决策；STAGE_1_ACCEPTANCE §4 R6 教训。判官输出推荐 + 评分，作者本人 A/R/S 才是 acceptance 信号。**不要建议**把 judge 接入 visual_review_cli 自动决策。
- **视觉判官 prompt 是粗起一版**——12 维度 / 阈值 14 = 24 是凭直觉初设；跨模型校准推到阶段 2/3。**不要建议**现在做精细化校准。
- **macOS `open` 命令是平台依赖**——非 macOS 必须用 `--web`；任务明文不要加 Linux/Windows 原生预览（YAGNI）。**不要建议**加 `xdg-open` / `start` 分支。
- **`--web` 模式用最小静态 HTML + `http.server`**——不引 React / Vue / Tailwind / 任何前端框架（阶段 3 的工坊化 UI 才考虑）。**不要建议**升级为 SPA。
- **`experiments/` 已在阶段 1 .gitignore 覆盖**（沿用）——**不要建议**显式 ignore 新批次目录。
- **`prompt_packages/` 用 symlink，OSError 时 fallback copytree**——这是任务"软链或拷贝"明文要求；symlink-first 是为节省磁盘 + 保持随后 author rename `_pending/` 的反映；**不要建议**默认 copytree（重复存储）或 symlink-only（Windows 无管理员权限会失败）。
- **visual_review_cli 跳过尚未 import 的资产（不在 manifest）**——是 P1.4 工作流："先 import，再 review"；surface "awaiting import" 计数让作者知道需先跑 image_import。**不要建议**让 review CLI 直接调 image_import（混淆职责）。
- **visual_review_log.jsonl 写在 `<batch-dir>/visual_review_log.jsonl`**（与 results.jsonl 同 batch 目录），与文本版 review_cli 的 `<batch-dir>/review_log.jsonl` 同结构。**不要建议**改全局共享 log。
- **visual_metrics 数据全从结构化 log 读，绝不扫目录**——GPT-5.5 L2 critique 4.7 修补；保护"机械通过率"等指标的可重算性。**不要建议**回退扫 `_pending/` / `_rejected/`。
- **`acceptance_rate` 分母 = imported（不是 reviewed）**——任务明文；意图是"半审一半的 batch 给出下界"，作者一眼能判断"还差多少没审"。**不要建议**改成 reviewed 分母（会高估）。
- **`parity_smoke_status: "not_ran"` 是 forward-compat 占位**——T-1.5.9 实现 OpenAIImageProvider + visual_parity_smoke 时会覆写；本任务**故意不实施 parity smoke 脚本**（GPT-5.5 L2 critique 4.6 修补）。**不要建议**本会话补 parity smoke。
- **CLI flag 命名 `--target` / `--target-type` / `--asset-role`**（不是 `--target-ref` / `--asset-kind`）——GPT-5.5 L2 critique 4.3 修补：与 schema 字段名 `target_ref` / `asset_role` 对齐。**不要建议**改名。
- **`expressions` 默认有 10 个标签**——为了让 vellin n=10 batch 一行命令跑通；`generate_visual._check_requirement` 会拒收 `n > available`。**不要建议**把默认改回 3-5（会让作者每次手填）。
- **`_resolve_batch_name` 优先读 envelope 内 `batch_name` 字段，再 fallback 解析目录名**——GPT-5.5 L2 critique 4.7 风格；保护 batch_name 漂移导致的 metrics 错算。**不要建议**只用目录名。
- **判官 prompt 三种输入场景显式分开**（网页 attach / CLI base64 / 本地路径）——GPT-5.5 L2 critique 5.2 修补：防作者把本地路径粘到网页端被判官当真 hallucinate 评分。**不要建议**合并表述。
- **判官只评 12 维度，不评机械维（size / format / has_alpha）**——机械维已由 image_validator + image_import 拦截；R8 教训"机械可数值化维度不让 LLM 评"。**不要建议**给判官加机械维度评分。
- **判官 N/A 维度处理（V10 仅 character_sheet 多张时评）**——总分按 22 算；阈值 13；prompt 内显式说明。**不要建议**强制给所有维度打分。
