# 本任务关键设计决策（不要当 bug 抓）

- **仅做可数值化机械预检**；语义判断（如"是否含可识别角色 / 是否符合本体卡"）推到 T-1.5.8 视觉 AI 判官（STAGE_1_ACCEPTANCE §4 R8 教训：机械可检测维度不让 LLM 评——LLM 在可数值化维度系统性放水）。**不要建议**在本任务加任何 LLM / 内容相似度 / 美学评估。
- **magic bytes 校验是为了防文件名伪造**（jpeg 内容伪装为 .png 扩展名），不是过度设计；任务提示词显式要求"读 magic bytes 而非依赖扩展名（防伪造）"。**不要建议**移除 magic-byte 检测改回扩展名信任。
- **测试图现场用 Pillow 生成到 tmp_path_factory**，不提交二进制；任务提示词显式要求"不要把测试图作为二进制文件提交到 git（用 Pillow 现场生成）"——避免仓库膨胀。**不要建议**把 fixture 改成 commit 到 `validator/tests/fixtures/`。
- **fixture 命名遵循 GPT-5.5 L2 critique 5.1 修补**（`small_character.png` / `perfect_character.png` / `perfect_background.png` + too_small / jpeg_disguised / with_exif / alpha_in_bg）；旧命名（`valid_character.png` 配 512×768 故意 RESOLUTION_TOO_LOW）已弃用——命名误导。**不要建议**回滚到旧命名。
- **Pillow 依赖追加到 pyproject.toml 是 T-1.5.4 唯一允许的 pyproject 改动**（T-1.5.1A 显式不加该依赖；与阶段 1 加 google-genai 同级别）。**不要建议**把 Pillow 升级为 optional-dep，本任务设计为运行时基础校验，validator 校验需在所有部署中可用。
- **不纳入三层 ValidationReport**（schema / graph / cons）是有意——image_validator 的定位单位是单个文件路径而非 graph dict，与 JSON 三层校验体系并行。**不要建议**把 ImageValidationError 合并到 Issue / 把 validate_image_asset 接到 validate(graph_dict) 入口。
- **`require_aspect_ratio` 默认 None（不开启）**是有意；T-1.5.7 入库时按 asset_kind 配置开启（character_sheet 通常竖图、scene_background 通常横图，但本任务不预先 hardcode）。**不要建议**给默认开启。
- **ALPHA_REQUIRED / ALPHA_FORBIDDEN 是 error 不是 warning** 是有意——这是入库硬卡：character_sheet 必须可叠放在场景上（透明背景）、scene_background 必须不带 alpha（避免合成时漏底）。**不要建议**降级为 warning。
