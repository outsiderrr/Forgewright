### 3.1 [SAFETY] generator/visual_review_cli.py:203 — `--web` 静态服务可用 `..` 读出 serve_root 外文件
**问题**：`_RootedHandler.translate_path()` 把请求路径 `unquote()` 后直接 `(serve_root / rel).resolve()` 返回，没有检查解析结果仍在 `serve_root` 下。访问 `/../../../../etc/passwd`、编码后的 `%2e%2e`，或指向外部的 symlink，都可能被 `SimpleHTTPRequestHandler` 当成合法本地文件/目录列表服务出去。`_build_index_html()` 也直接拼接 `asset.target_ref` 等字段，缺少 HTML 转义，虽然当前导入路径多半给的是安全值，但这不是安全边界。
**为什么 CRITICAL**：T-1.5.8 明确把路径遍历 / HTTP server 安全列为高风险面；本问题让本地 Web 预览从“只看缩略图”变成任意本地文件读取，属于安全必修。
**建议修复**：
```python
# 当前
rel = unquote(path).lstrip("/").split("?", 1)[0].split("#", 1)[0]
return str((serve_root / rel).resolve())

# 改为：解析后强制仍在 serve_root 内；HTML 生成时同时 escape/quote
from html import escape
from urllib.parse import quote, unquote, urlsplit

root = serve_root.resolve()

class _RootedHandler(handler_cls):  # type: ignore[misc, valid-type]
    def translate_path(self, path: str) -> str:
        rel = Path(unquote(urlsplit(path).path).lstrip("/"))
        candidate = (root / rel).resolve()
        try:
            candidate.relative_to(root)
        except ValueError:
            return str(root / "__forbidden__")
        return str(candidate)

    def list_directory(self, path: str):  # optional: no directory listings
        self.send_error(403, "Directory listing disabled")
        return None

# _build_index_html 内：
safe_target = escape(str(asset.target_ref))
safe_src = "/" + quote(asset.file_path, safe="/")
```
**模块边界状态**：✅ 在边界内（可修）

### 3.2 [ERR] generator/visual_metrics.py:146 — 按文档导入资产后 metrics 会把 imported 算成 0
**问题**：`compute_visual_metrics()` 只用 `import_log.read_all(batch_name=batch_name)` 取机械导入结果。但 T-1.5.8 作者手工流程写的是 `python -m generator.image_import --all-pending`，没有 `--batch-name`；T-1.5.7 的 import log 因此会写 `batch_name: null`。结果是图已入库、review log 也有 A/R，metrics 仍显示 `total_imported=0`、`mechanical_check_pass_rate=None`、`acceptance_rate=None`。
**为什么 CRITICAL**：T-1.5.8 的核心产物就是给 T-1.5.10 验收复算 `acceptance_rate` / 机械通过率；作者按任务文档执行会得到不可用指标，直接阻塞“接受率 ≥ 50%”验收判断。
**建议修复**：
```python
# 当前
import_rows = import_log.read_all(batch_name=batch_name) if batch_name else []

# 改为：仍只读结构化 log，但在 batch_name 缺失时用 results.jsonl 的 stubs 关联
result_stubs = {
    r.get("result", {}).get("asset_id_stub")
    for r in results
    if r.get("result", {}).get("asset_id_stub")
}
all_import_rows = import_log.read_all()
import_rows = [
    r for r in all_import_rows
    if (
        batch_name is not None
        and r.get("batch_name") == batch_name
    )
    or (
        (r.get("batch_name") in (None, ""))
        and r.get("asset_id_stub") in result_stubs
    )
]
```
同时补一个单测：results 有 3 个 stub，import_log 这些 stub 的 `batch_name` 为 `null`，metrics 仍应算出 `total_imported=3` 和正确 acceptance 分母。

### 4.1 [SAFETY] generator/visual_experiment.py:229 — `--batch-name` 可带路径分隔符，把输出写出 experiments/
**问题**：`batch_dir = out_root / f"{ts}_{batch_name}"` 直接使用 CLI 传入的 `batch_name`。如果传入 `x/../../../docs/reviews/oops` 这类值，`mkdir()` 和 `results.jsonl`/`summary.txt` 写入会逃出 `generator/experiments/`。这是本地 CLI，但仍是越界写入口，而且 batch_name 也进入后续日志关联。
**为什么 IMPORTANT**：它不需要跨模块即可修复，且属于输入校验缺口；阶段工具通常由作者手打命令，误输入斜杠也会产生难懂的目录布局。
**建议修复**：
```python
# 当前
batch_dir = out_root / f"{ts}_{batch_name}"
batch_dir.mkdir(parents=True, exist_ok=True)

# 改为
_BATCH_NAME_RE = re.compile(r"^[A-Za-z0-9][A-Za-z0-9_.-]{0,80}$")

def _validate_batch_name(batch_name: str) -> str:
    if not _BATCH_NAME_RE.fullmatch(batch_name):
        raise ValueError(
            "batch_name must use only letters, numbers, underscore, dot, or hyphen"
        )
    return batch_name

safe_batch_name = _validate_batch_name(batch_name)
root = out_root.resolve()
batch_dir = (root / f"{ts}_{safe_batch_name}").resolve()
batch_dir.relative_to(root)  # defense in depth
batch_dir.mkdir(parents=True, exist_ok=True)
```
**模块边界状态**：✅ 在边界内（可修）

### 4.2 [ERR] generator/visual_metrics.py:168 — 重复 review_log 行会把 acceptance_rate 算高，甚至超过 100%
**问题**：metrics 把 `visual_review_log.jsonl` 里所有含 `accepted` 的行都计入分子，但没有按 `asset_id` 去重，也没有限制为本批 imported 的 asset。正常 CLI 重跑会跳过已审资产，但并发跑两个 review CLI、手工拼接 log、或旧日志残留时，同一个 `asset_id` 两条 `accepted=true` 会让 `len(accepted) / total_imported` 虚高。
**为什么 IMPORTANT**：用户特别要求核对 idempotency 边角；验收口径的分母固定为 imported，分子必须是“已导入资产中作者最终接受的唯一 asset 数”，否则会高估接受率。
**建议修复**：
```python
# 当前
decisions = [r for r in review if "accepted" in r]
accepted = [r for r in decisions if r.get("accepted") is True]

# 改为：只统计 imported asset_id，重复时保留最后一条 append-only 决策
imported_ids = {
    r.get("final_asset_id") or r.get("asset_id_stub")
    for r in imported_rows
}
decisions_by_asset: dict[str, dict] = {}
for rec in review:
    asset_id = rec.get("asset_id")
    if "accepted" not in rec or asset_id not in imported_ids:
        continue
    decisions_by_asset[asset_id] = rec

decisions = list(decisions_by_asset.values())
accepted = [r for r in decisions if r.get("accepted") is True]
```
补一个单测：同一 `asset_id` 两条 review 行时，`reviewed_count` 按 1 算，`acceptance_rate` 不得超过 `1.0`。
**模块边界状态**：✅ 在边界内（可修）
