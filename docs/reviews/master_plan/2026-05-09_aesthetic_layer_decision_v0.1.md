## 2. 三 Gap 诊断（L1 独立判断）

### Gap 1：结构化审美偏好档 0 进度

**严重性**：🟡 中等

- 工程问题——schema + prompt 模板可以做（候选 ADR-028 AestheticPreference schema）
- 单独看**不是阻塞**——可在 Gap 2 实证基础上落地
- 与 Gap 2 互锁：没偏好档，作者锚点也没法结构化沉淀；没锚点，偏好档字段也填不出来

### Gap 2：作者审美锚点未建立

**严重性**：🔴 战略级 + 时间不可压缩

- **非工程问题**——作者本人需读 N 部经典作品在温度 / 节奏 / 弧光 / 价值四维各列偏好
- **时间无法工程加速**——读经典 + 形成偏好档独立于 Forgewright 工程节奏
- 没锚点 → [A]/[R]/[S] ground truth 漂移 → Wilson 95% CI 统计意义崩塌
- feedback memory（2026-05-05）真实建议**仍然成立**——但**可在阶段 3 内通过精选 1-3 部经典剧本压缩**（v0.2 选项 5 核心洞察）

### Gap 3：AI 多维审美能力未验证

**严重性**：🟡 中等 + 依赖 Gap 1 + Gap 2

- 即使 AI 能按结构化偏好生成内容，Gap 1+2 没解决前**无法验证**
- baseline_011 N=15 100% gross_pass 仅证工程层（schema/mechanical/topology/sampling）；审美层完全跳过
- 选项 5 下，T-3.10 直接作 dry-run + 验证（不需阶段 4 起手周）

## 4. 五选项 + 利弊 + 推荐

### 选项 1（路径 A 优化版）：纯工程层 T-3.10 + 审美层降为 advisory

- 工程层达标即过；审美层 [A] 作 baseline measurement 不作 gate
- **缺点**：Gap 1/3 仍 0 进度，阶段 4 启动期工程负担集中

### 选项 2（路径 B / L2 提议）：阶段 3 内补 3 任务（延期 2-4 周）

- 加 T-3.X1/X2/X3；然后跑 T-3.10
- **缺点**：作者读 30 本经典节奏可能 1-3 个月，阶段 3 节奏被非工程任务卡住

### 选项 3（路径 C / L2 提议）：重定义 T-3.10 范围

- 缩 N=10 → N=3-5；审美层从 gate 改 baseline measurement
- **缺点**：3-5 场景看不到"批量 + 一致性 + 审阅 UI 真用"工具链 ergonomic；ADR-022 + ROADMAP §阶段 3 大修订

### 选项 4（v0.1 L1 原推荐）：分层处理 + Gap 显式映射阶段 3/4 边界

- 阶段 3 内立空 schema 容器 + prompt hook；锚点 + dry-run 推阶段 4 起手 3-4 周
- **缺点**：ADR-028 v0.1 凭直觉立 → 阶段 4 起手期 v0.2 修订必然；阶段 4 起手 3-4 周非工程周

### 选项 5（v0.2 主推荐 / 作者方案）：用经典剧本反向归纳抽象层 + 同步建立锚点

**核心思路**：作者**通过精选 1-3 部经典剧本**反向归纳抽象层（人物弧光 / 剧本节奏 / 温度 / 价值轴），同时**实证建立作者审美锚点**。两件事合并做。然后基于实证归纳出的字段集立 ADR-028 + schema 落地 + prompt hook，最后跑 T-3.10（审美层 gate 真可兑现）。

- **不动 feedback memory**（真实建议被正面吸收，不需修订）

#### 优点（对比 v0.1 选项 4）

1. **ADR-028 schema 字段集基于实证**——不是 L1 凭直觉，质量更高
2. **抽象层与锚点同步建立**——不会脱节；不会出现"先立 schema → 阶段 4 起手期发现字段集错"
3. **T-3.10 [A] gate 重新合理可兑现**——保留 STAGE_3_TASKS v1.0 §1 原阈值，不需降级
4. **L1 文档修订量更小**——4 份小改 + 1 份新立（vs 选项 4 的 6 份大改 + 1 份新立 + 1 份降级修订）
5. **省一次 ADR-028 v0.2 修订**（v0.1 选项 4 几乎必然要 v0.2）
6. **与 strategy_calibration v0.1 哲学同源** —— "工具是杠杆，不是终点 / 工具改进的唯一合法理由 = 能更快达成 A" —— 读经典剧本归纳抽象层是为 A 完成做的最高杠杆投入

#### 缺点 / 风险

1. **阶段 3 延期 1-3 周**（作者读 3 部经典节奏决定）——但**与 strategy_calibration §3 (a+) 工具杠杆哲学** 同源（不是反向 trade）；净时长 vs 选项 4 大致相当（选项 4 把 3-4 周从阶段 4 起手挪到阶段 3 后置；选项 5 把 1-3 周放阶段 3 内）
2. **抽象层归纳质量取决于读三部经典覆盖面**——单一作品偏窄；选三部覆盖不同风格（CoC 调查驱动 × 2 + 极乐迪斯科对话技法 × 1）能保证维度覆盖度
3. **作者归纳方法论需要框架**——避免"读了但抽象层没沉淀"；§7 指引模板覆盖此风险

### 推荐：选项 5

理由：
- ADR-028 字段集基于实证 vs 凭直觉
- T-3.10 [A] gate 不需降
- L1 文档修订量更小
- 与 strategy_calibration v0.1 北极星 + 工具杠杆哲学同源
- 净时长相当

### 7.3 归纳方法论

**阅读节奏**：

- 1-3 周读完三部（按作者节奏；不强制赶节奏）
- 推荐顺序：Crimson Letters（教科书结构清晰）→ Deadlight（CoC 复杂样本）→ 极乐迪斯科原版（对话技法 / 反差风格）

**阅读方法**：

- 第一遍通读，理解整体结构 + 风格
- 第二遍精读，按 §7.1 对照表填四维
- 边读边记，**不要**"读完整本再开始记"——细节会忘

**填表节奏**：

- 每部读完后**立即填一份对照表**（推迟会丢失精读时的具体场景印象）
- 填表时不追求一次完美——可以留空位 / 反复修订

**整合节奏**：

- 三部全读完后**整合**产出 `/docs/AESTHETIC_PREFERENCES.md` v0.1
- 整合时检查"四维是否够用 + 有没有遗漏维度"——发现新维度立即记进对照表 §5 + 整合到 AESTHETIC_PREFERENCES.md §3

**反思节奏**：

- 整合完后**反复读一遍**自己写的 AESTHETIC_PREFERENCES.md v0.1
- 检查"如果 AI 拿到这份偏好档生成场景，会生成什么"——能想象出具体场景吗？想象不出来 = 字段不够清晰，需补 / 改

**不追求一次完美**：

- v0.1 偏好档可在 T-3.10 + 阶段 4 修订
- T-3.X0 目标 = **建立审美锚点 v0.1**，不是终极锚点
- 字段不全 / 偏好模糊 → 阶段 4 起手期补；不要因追求完美卡住阶段 3 节奏

**极乐迪斯科特别提醒**：

- 作者已明示**不吸收**思维内阁 / 内心独白
- 读极乐迪斯科时**聚焦**：对话选项丰富度 + 多元化、技能驱动的对话、NPC 描写颗粒度、世界观信息密度、检定后果多样性
- **跳过**：思维内阁系统、内心独白段落
- 阅读对照表 §1-4 填四维仍按常规；新发现维度（§5）特别记从极乐迪斯科吸收的对话技法相关维度
