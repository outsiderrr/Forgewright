## 3. 人物弧光（救赎 / 堕落 / 成长 / 静止；强 / 中 / 弱）

### 该作品弧光特征

- **主角（调查员）弧光**：弱（CoC 调查员通常不强求弧光，只是"调查 → 发疯 / 幸存"）
- **NPC 弧光**：莱特有微弧光（双重生活 → 临终高尚一举）；其他 NPC 弧光弱（多数是揭示型 NPC，每人三层面具但本身不变化）
- **真凶 NPC 的"若被选为真凶"段**——这一设计让同一 NPC 在不同游戏里有不同"暗面"，等于**弧光由守秘人选**

## 5. 新发现维度（4 维外）—— 元结构判断 ⭐

### 核心洞察（本次会话最有价值的产出）

**Crimson Letters 是骨架式作品**——CoC 模组写给守秘人（GM）跑团时即兴用，**留白大量"GM 抉择空间"**，而 Forgewright 引擎要求**确定性 JSON 对话图**。两者之间存在结构鸿沟。

作者本次会话的核心判断：

1. **CoC 骨架结构 OK** —— NPC + 钩子 + 事实与线索 + 守秘人笔记 + 时间线 + 多嫌疑人结构，**可借鉴**
2. **文本层未定** —— 本作品没具体对白可评（除塞西尔·亨特发疯关键词触发台词那段，是整本剧本唯一的具体文本），**评不了 AI 文本质量**
3. **比审美更核心的工作 = GM 抉择空间结构化** —— 这才是 T-3X-1 工程会话立 schema 字段集的真正阻塞点

### GM 抉择空间的 7 种具体形式（Crimson Letters 反向归纳）

| GM 抉择空间形式 | Crimson Letters 中的体现 | 候选结构化方案（脑暴，未拍板） |
|---|---|---|
| **真凶选择**（5 候选 NPC） | 模组列考特 / 罗奇 / 弗林德斯 / 维克 / 自定，由 GM 选 | 元参数（culprit_id），开场定 / 动态定 / 随机 |
| **NPC 反应**（多套行为按玩家行为切换） | 每个 NPC 有"角色扮演钩子" + "守秘人笔记" + "若被选为真凶"段 | NPC 状态机 + 反应矩阵（state × event → next_state + response） |
| **威胁显现节奏**（5 征兆何时触发） | "通路征兆" 5 种由 GM 决定何时触发 | 倒计时机制（行动数 / 事件 / 时间） |
| **多解决路径**（藏 / 销毁 / 神话技能） | 模组列 3 种结局，玩家选 + GM 评判 | 多结局分支（end state by world state） |
| **场景扩展**（GM 加剧情线 / 派系） | 模组明文鼓励 GM 加自己的剧情 | 场景模板 + 插件式追加 |
| **难度调整**（玩家莽撞则加难度） | 模组写"对瓷器店里横冲直撞的莽夫不该手软" | 难度参数（影响检定 DC / NPC 警觉度） |
| **即兴**（红鲱鱼地点临场变黑帮入场点） | 试玩示例：霍布豪斯宅邸临场变成黑帮入场点 | **不可完全结构化** ⚠️ |

### 关键判断（赌注）

**最后一行最关键**——GM 即兴 = 人类直觉，**无法完全结构化**。

Forgewright 工具一期的核心赌注 = **"AI 海量预生成 + 人工审阅 = 给玩家伪即兴体验"**。

> 如果这个赌注不成立（AI 无法预生成足够丰富的内容），整个工具一期定位需要重新审视。
>
> 这是本次会话发掘出的最深层赌注，应进 DEBATE_NOTES.md。

### 两种工作场景的共同点（重要！）

无论是 **(场景一) 改编已有 CoC 模组**，还是 **(场景二) 原创**，**核心都是同一个工作流**：

**"叙事意图（人脑里 / 模组里）→ 确定性 JSON 对话图（引擎可执行）"的转换**

差别只在输入端：

| 场景 | 输入 | 工作流 |
|---|---|---|
| 改编模组 | 已有材料库（NPC + 钩子 + 留白） | 结构提取 + 填补留白 |
| 原创 | 作者一句话 / 主题 | 结构生成 + 填充细节 |

**输出端共用同一份 schema**——所以抽象层一旦立起来，两种场景都能复用。

## 6. 总结：本作品我吸收的 N 条"抽象层维度补充"

### N=6 条核心吸收

1. **CoC 骨架可借鉴**：NPC 资料卡（外貌 + 性格 + 与主角关系 + 事实线索 + 角色扮演钩子 + 守秘人笔记 + 若被选为真凶）这套字段，可作为 Forgewright schema 中 `npc.json` 字段的参考起点。
2. **多嫌疑人结构可借鉴**：开场列 N 个 NPC，每个都可能是真凶，最终由元参数确定——这是 schema 里"真凶选择"机制的合法形式。
3. **5 级威胁征兆可借鉴**：威胁逐级显现的设计是 schema 里"倒计时机制"的合法形式。
4. **3 种结局可借鉴**：藏 / 销毁 / 神话技能——多结局分支是 schema 里"world_state → ending"映射的合法形式。
5. **塞西尔·亨特关键词触发台词**：整本剧本唯一的具体文本样本（约 8-9 句疯狂引用 + 爱伦·坡致敬）。如果作者愿意评估，这是该作品里唯一可给"AI 文本质量"反馈的素材。**作者本次未深入评**，待后续 demo 文本补充。
6. **GM 抉择空间 = 引擎抽象层核心问题**：见 §5。**这是本次会话最有价值的产出**，已传递给 L2 提示词 → T-3X-1 工程会话。

- **作者本次会话核心决策**：**T-3X-0 收尾**（不再继续读 Dead Light / 极乐迪斯科）。 理由：识别出真正阻塞 T-3X-1 的是"GM 抉择空间结构化"，继续读其他模组回答不了这个问题。
