### 4.1 [TEST] schema/tests/test_stage2_ontology_schema.py:458 — state_path_slug 反查链没有被测试锁住

**问题**：当前 `test_gold_scene_paths_all_within_state_namespace_whitelist` 只检查 path 首段是否落入 `world / faction / relationship / flag / player` 白名单。`_collect_paths_from_node()` 在第 433-438 行只收集 prefix，所以 `relationship.vellinn.trust` 这种 slug 拼错但 prefix 正确的路径仍会通过本测试。T-2.2 关键决策要求 gold scene 的 `relationship.vellin.trust` 能反查到 `char_vellin.state_path_slug == "vellin"`，这里还没有覆盖。

**为什么是 IMPORTANT**：这是 STAGE_2_TASKS §2.6 / ADR-016 的 Q1 核心兼容点；T-2.4 的 `BOND_ID_UNKNOWN` 机械预检会依赖这条链。如果这里漏测，后续 prompt 或 validator 可以在 slug 层悄悄漂移。

**修复建议**：
```python
# 当前：只检查 namespace prefix
illegal = all_prefixes - set(STATE_PATH_NAMESPACES)
assert illegal == set()

# 建议：额外检查 relationship.<state_path_slug> 反查到 character entity
ontology = _load_ontology()
slug_to_character = {
    e["state_path_slug"]: e["id"]
    for e in ontology["entities"]
    if e.get("type") == "character"
}

relationship_paths = _collect_full_paths_from_gold_scene(gold, prefix="relationship")
for path in relationship_paths:
    _, slug, *_ = path.split(".")
    assert slug in slug_to_character, f"{path} cannot resolve to a character state_path_slug"

assert slug_to_character["vellin"] == "char_vellin"
```

### 4.2 [SCHEMA] schema/character.schema.json:93 — visual_assets 的 shape 兜底没有覆盖 ontology 已有数据

**问题**：`character.visual_assets` 与 `location.visual_assets` 的 items 只约束为 generic object，这是可以接受的 codegen 权衡；但报告/文档同时说完整 ImageAsset shape 会由 `image_validator` 兜底。实际 `state/ontology/__init__.py:20-29` 只 `json.loads()` 后按 `entity["id"]` 建索引，不会校验 embedded `visual_assets`。`generator/image_import.py:461-555` 确实在导入时跑 image 机械校验和 ImageAsset Pydantic，但这只覆盖 import 入口，不覆盖现有或手改的 ontology 数据；一个 `{}` 仍会通过 character schema 和 loader。

**为什么是 IMPORTANT**：CLAUDE.md 规则 6 要求 JSON Schema 是唯一 schema 来源。既然 character/location schema 为避免 codegen 复杂性放宽了 `visual_assets`，就必须有测试或确定性校验补上已入本体数据的 ImageAsset shape，否则 PR body 中的兜底链不成立。

**修复建议**：
```python
# 保留 character/location schema 的 generic object 设计，但在 /schema/tests/ 增加回归：
def test_embedded_visual_assets_still_match_image_asset_schema() -> None:
    image_asset_validator = _validator("image_asset.schema.json")
    ontology = _load_ontology()

    for entity in ontology["entities"]:
        for asset in entity.get("visual_assets", []):
            errors = sorted(image_asset_validator.iter_errors(asset), key=lambda e: e.path)
            assert errors == [], (
                f"{entity['id']} visual_assets item failed image_asset.schema.json: "
                + "; ".join(f"{list(e.path)}: {e.message}" for e in errors)
            )
```
