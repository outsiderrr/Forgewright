## 二、场景契约

- **玩家目标**：在不暴露调查意图或引发酒馆内危险的前提下，从露西处取得莱特藏东西的小屋位置、到达方式和铁盒相关信息，并判断角落男人是否影响谈话安全。
- **NPC 目标**：露西想把莱特留下的麻烦转交给玩家，让自己脱身；她愿意提供足够线索让玩家离开酒馆去找小屋，但不想在公共场合说出会把她和莱特之死、私藏物、地下酒吧牵连起来的细节。
- **NPC 恐惧**：露西害怕角落男人或楼下的人听见“小屋”“钥匙”“教授”“铁盒”等关键词后认定她知情；也害怕玩家太直接、太急迫或太高调，使她看起来像在协助调查，从而被报复或被警方、私酒贩、未知势力一起盯上。
- **禁则（本场不许发生 / 不许写出的事）**：
  - 不揭示完整真相。
  - 不让露西解释神话体系或命名超自然来源。
  - 不让玩家在这里直接找到铁盒。
  - 不让露西死亡、被绑走或永久失联。
  - 不写成完整小说路径。
  - 不产生五个结局。
  - 不生成完整 DialogueGraph JSON。
  - 不把“信任高就全说、信任低就失败”做成单一门槛。
  - 不让角落男人立刻确认身份或直接动手解决冲突。
  - 不把露西写成全知证人；她只能知道路线、见闻、传闻和她愿意承认的部分。

## 四、逐节点填空单（树序）

三类节点各要写什么（字数等硬指标另见「五、文风与量化契约」）：

- **选择节点（choice）**：narration（250-400 汉字，写厚——每句至少承担一个功能：
  空间信息 / 视线与听觉风险 / NPC 物理状态 / 行动机会 / 可回收线索 / 少量物理异常）+
  NPC 对白（关键信息由 NPC 自己说）+ 逐条把已锁定的选项意图转写成玩家第一人称台词
  （每条 ≤25 汉字）。**非开场节点的旁白不要重新做进场式全景描写**
  （不要再从门、灯光、整间屋子的布置写起），只写此刻的变化、动作与新的可观察细节。
- **对话链（beats，单选项拍）**：每拍 = 玩家看到的一屏——narration（约 60-120 汉字，白描，
  承担空间 / 物理动作 / 可回收线索之一）+ NPC 对白 1-2 句 + 一句把对话推进到下一拍的接话
  （continue，≤20 汉字，自然口语）。写出「NPC 说一点 → 玩家接一句 → NPC 再说一点」的来回感。
  - **每拍只揭本拍锁定的线索**，不得提前揭后面拍的；线索标了残缺形态的
    （如「只给残缺记号」），只能写到该残缺程度，不得写出完整版本。
  - **承接**：第 N+1 拍的 NPC 对白必须先**承接第 N 拍玩家刚说的话**（回应它，或明确拒答），再推进新线索；不许答非所问、不许自顾自往下讲。链的第一拍同理，要承接玩家进入本链时说的那句选项台词。
  - **接话（continue）**：自然口语别电报体（「你为什么这么着急？」对，「为什么急？」错）；
    不把 NPC 刚说完的内容变成问题再问一遍；没有新追问点时用简短确认（「我知道了。」）或
    动作（「[记下路标]」）推进；末拍可收束。
  - 多入口的链（下面会标出）：第一拍的旁白与对白必须对每个入口都成立。
- **终止节点（end）**：narration（80-200 汉字，收束旁白——交代玩家带着什么离开、
  场景怎么收）+ NPC 收尾 0-2 句（可选；关键信息前文已给，这里不补新线索）。**没有玩家选项。**

### ◆ opening（选择节点 · 4 选项）

- 局面：玩家刚在希博公路酒馆内接近露西；她在公共吧台附近，周围有酒客、通往地下酒吧的楼梯和靠窗角落的陌生男人。露西没有初始信任，既想摆脱莱特留下的麻烦，又害怕任何公开谈话把她和莱特之死牵连起来。角落男人桌上没有酒，只有报纸，位置能同时看见吧台和露西。

  - 露西会回避“小屋”“钥匙”“教授”“铁盒”等敏感词，显示她担心被旁人听见。

  - 〔basement_line_b4〕本拍揭露：可继续调查的残缺路标为“希博公路北侧 / 第七码碑 / 断了半截的电线杆”，没有明确说明小屋名称和准确转入点。（末拍：接话可收束，如「我知道了。」或一个动作）

### ◆ end_basement_leave（终止节点）

- 入口：basement_line 链讲完
- 功能：玩家获得保底追查方向但缺少铁盒、钥匙和异常线索，需要在场景外继续补足。
- 收束要求：narration 80-200 汉字，白描收束（交代玩家带着什么离开、场景怎么收）；
  dialogue 可选 0-2 句（不补新线索）；**无选项、无接话**。

### ─ pressure_line（对话链 · 4 拍）

- 入口：opening 选项 4〔直接逼问莱特相关事项并暗示后果〕
- 功能：高压路径让露西迅速切断深入谈话，只吐出防止玩家继续纠缠的残缺坐标和最低限度物件线索。
- 链讲完去向：end_pressure_leave（终止节点）
- 逐拍锁定线索（每拍只揭本拍这条，不许提前）：
  - 〔pressure_line_b1〕本拍揭露：保底残缺路径为“北侧、第七码碑、断杆”；残缺形态为没有街名、没有土路绕行说明、没有小屋完整称呼。
  - 〔pressure_line_b2〕本拍揭露：莱特有东西留在那里；残缺形态为不说“铁盒”原词，只让玩家知道目标不是人也不是文件袋。
  - 〔pressure_line_b3〕本拍揭露：露西否认知道那东西里面是什么；残缺形态为无法判断她是真不知道还是拒绝承认。
  - 〔pressure_line_b4〕本拍揭露：高压让露西更害怕角落男人听见，她不会给钥匙位置、楼下传闻或空间异常细节。（末拍：接话可收束，如「我知道了。」或一个动作）

### ◆ end_pressure_leave（终止节点）

- 入口：pressure_line 链讲完
- 功能：玩家没有彻底失败，但只得到残缺追查方向，并明显降低露西后续合作意愿。
- 收束要求：narration 80-200 汉字，白描收束（交代玩家带着什么离开、场景怎么收）；
  dialogue 可选 0-2 句（不补新线索）；**无选项、无接话**。

## 五、文风与量化契约

### 5.1 三类正文的分工（谁能写什么）

三类正文各管一摊，别越位：

**旁白（narration）——第三人称叙述**
- 写：物理环境（光线 / 声音 / 气味 / 布置 / 时间）、客观可见的动作、玩家能直接观察到的细节。
- 不写：NPC 的内心活动（让 NPC 用话或动作带出来）；NPC 掌握的信息（必须由 NPC 在对白里自己说，
  旁白不代述——「她说莱特在人前是教授，人后是另一种人」这种写法不合规，要改成 NPC 直接说）；
  玩家的内心活动 / 价值判断（留给选项）；总结性评价（「她很狡猾」——用具体行为代替）。
- 旁白可以带 NPC 名字写动作 / 表情 / 视线 / 物理姿态（「露西把空杯子往水槽里一放」
  「她的指尖按着那张名片」），也可以以「你」为主语写玩家的身体感受（疲倦 / 寒意 / 心跳），
  但不要替玩家做价值判断或决定（「你决定要……」是错的）。
- 旁白中的玩家一律写「你」，**不得出现「玩家」二字**。

**NPC 对白（dialogue）**
- 写 NPC 此刻说出口的话本身（必须是这个角色会说的措辞与节奏），交稿时裸正文、不带引号包裹。
- **场景的关键信息必须由 NPC 自己说出来**，不能让旁白替代。

**玩家台词（options / continue）**
- 写玩家此刻要说的话或要做的动作本身，一律**第一人称语言**；动作可写成方括号形式
  （如「[放下几枚硬币]」「[记下路标]」）。
- 不要写成「追问 / 安慰 / 威胁 / 调查」这类第三人称意图标签。
- 如有检定标记可保留「[技能名]」前缀作为激活提示，但主体必须第一人称。

### 5.2 禁则 · 任何文风都不许犯

### AP-2: 修辞失底（喻体与本体无共同点）
- 用比喻 / 类比前必须明示喻体和本体的共同点；说不清就直接白描，不用修辞
- 反例：「托盘在她指尖稳得像变戏法」（"变戏法" 与"托盘稳" 无共同点）
- 反例：「你别摆那副法官脸」（"法官脸" 究竟指什么——正义？审视？怀疑？——无线索）

### AP-3: 修辞方向 / 物理逻辑错误
- 用动词 / 修辞前检查物理方向 / 逻辑是否与场景一致
- 反例：「真正的热闹从后门那条窄楼梯往下漏」（"漏" 是从上往下，但热闹是从地下传上来的，方向相反）

### AP-4: 假靶子否定
- 否定句必须否定读者真实预期的靶子；不要竖一个读者本来没预期的靶子去否定
- 反例：「名字落下去时，露西脸上的笑没有碎」（没人预期笑会"碎"）
- 改法：直接写"露西脸上的笑只是停了一拍"

### AP-6: 锚定未说明的标准
- 不要引入读者不知道的"一般标准"作为对比基准
- 反例：「她的金发颜色新得过分」（"金发的一般标准"读者不知道）
- 改法：写具体细节（如"她的金发还有刚染过的化学气味"）

### AP-9: 读不懂的省略
- 留白前必须确保读者有线索能 fill in；如果线索还没出现，直接交代
- 反例：「有些人欠钱会怕打手，莱特怕的不是打手」（莱特怕的是什么？读者不知道）

### 5.3 本作文风预设：白描（预设条款；本作统一按此写）

## 文风预设：白描
- 白描为主：少抽象评价、少漂亮警句，不排比 / 不对仗 / 不堆成语 / 不押韵。
- 评价必须有可观察细节铺垫；优先物理细节（动作 / 视线 / 声音 / 气味 / 触感）。
- 超自然 / 异常以可复核的物理细节出现（最好经 NPC 之口），不堆"诡异 / 不祥"类形容词。

### AP-1: AI 对仗式 / 重复对应感过强
- 单段内避免成对对仗式结构；前半已暗示的，后半不要重复明示
- 反例：「前厅摆着……像一张给警察和好人看的脸；真正的热闹从后门那条窄楼梯往下漏」（前半已暗示"另一面"，后半冗余）

### AP-5: 总结代细节
- 先给具体行为 / 物理细节，避免直接给评价；如果必须给评价，前后要有具体细节铺垫
- 反例：「眼神却老练得不像二十五六岁的人」（"老练"是评价，无可观察细节）
- 正例：「她扫了你一眼，先看鞋，再看手，再看你有没有像常客那样急着找酒」（具体行为）

### 5.4 量化契约（主编按此审稿；写在指标内最省你返工）

| 槽位 | 要求 |
|---|---|
| 选择节点 narration | 250-400 汉字；每句至少承担一个功能；非开场节点不重做进场式全景 |
| 对话链每拍 narration | 约 60-120 汉字；白描 |
| 终止节点 narration | 80-200 汉字；收束 |
| 选择节点选项台词（options） | 每条 ≤25 汉字；第一人称 |
| 对话链接话（continue） | ≤20 汉字；自然口语别电报体 |
| NPC 对白（dialogue） | 关键信息由 NPC 自己说，旁白不抢答；对话链每拍 1-2 句 |
| 人称（旁白） | 玩家一律写「你」，不得出现「玩家」二字 |
| 人称（玩家台词） | 选择节点的选项是拿主意的话，**可以用「我」开头**（如「我不是来审你」）；对话链的接话则**第一人称隐含、别硬塞「我」**——两套约定并存，别混用。 |
| 承接（对话链） | 第 N+1 拍的 NPC 对白必须先**承接第 N 拍玩家刚说的话**（回应它，或明确拒答），再推进新线索；不许答非所问、不许自顾自往下讲。链的第一拍同理，要承接玩家进入本链时说的那句选项台词。 |

### 5.5 文风锚点（已验收样例——只学味道，严禁搬内容）

下面的样例出自**已验收文本**，只示范文风、节奏与口吻。样例里的人名、地名、道具、事实细节**不一定属于本场景**——一律不得照搬进你的正文；本场景的事实以上文「结构锁定」「场景契约」「逐节点填空单」为准。

#### 旁白该写成这样
- 办公室贴着冷藏库的外墙，墙面刷白，靠近门缝的地方有一圈潮气。桌上摊着几份空白病历纸，墨水瓶旁压着一串钥匙，金属牌上刻着冷藏库编号。走廊里的脚步声经过门外时会被瓷砖放大，又很快远去。惠特克罗夫特站在桌后，没有坐下，袖口卷到小臂，指节按在椅背上。他把死亡证明的副本翻到正面，又推回桌角，像是不愿让它离手太远。隔壁传来冷机低沉的震动，门框随之轻轻发颤；每一次震动停顿，他都会把视线转向那扇内门。你闻到消毒水、旧纸和低温金属混在一起的气味。窗帘半拉着，下午的光被切成窄条，落在他的领口和下颌上。他清了两次嗓子，目光从你的证件、手套、衣袖依次扫过，最后停在你是否带了记录本的位置。

## 六、输出格式（交稿必读；机器解析，逐字遵守）

交稿 = 一份纯文本：对下面清单里的**每个节点**交一个块，块与块顺序随意，
node_id 必须与清单逐字一致；不得增删节点、不得增删或改动选项序号。

语法（四个 key，只有这四个）：

```
[node: <node_id>]
narration: <旁白正文>
dialogue:
  - <NPC 的一句话>
options:
  1: <玩家第一人称台词>
continue: <接话>
```

- `narration:` 的值从冒号后开始，**允许多行**，直到下一个 key 行或下一个
  `[node: …]` 为止（多行值只有 narration 有）。
- `dialogue:` 块每行以 `- ` 开头，**裸正文不带引号包裹**（「」/“”都不要）；
  说话人不用写——本场对白统一是 露西（char_lucy）。
  0 行时整块省略，**不要留空的 `-`**。
- `options:` 序号行形如 `1: 台词`，一行一条写完；序号必须从 1 连续编到 N，不多不少。
- `continue:` 一句短话或动作，一行写完，不编号。
- `continue` 的值、options 序号行、dialogue 行都是**单行值**，
  换行续写会被判 E8（无法归属的游离行）。
