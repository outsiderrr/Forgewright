## 2. 系统性发现（按出现广度排序；= 引擎改进 backlog）

1. **收敛路由 × 静态文本 = choice pressure 稀释，最重者答非所问**（vick 两候选 major；lucy/c1 轻度）
   拓扑给的出边少于骨架的 3-5 选项时，语义不同的选项共享同一条后续链；链首拍不知道入口
   选项文本，最坏情况回应预设了玩家没说过的话（vick/c1 开场选项 4/5）。
   修复方向：①拓扑层让出边数贴近真实分歧数；②routes=2 时放宽骨架最少选项到 2；
   ③链首拍 prompt 注入"可能的入口姿态清单"，要求收敛安全的开头。
2. **旁白漏"玩家"二字**（4/6 候选，各 1-2 处，句式雷同"视线越过玩家肩侧"）
   正文/分拍 prompt 缺"旁白中玩家一律称'你'"显式规则。修复 = prompt 一行 + 引擎指标项。
3. **引号体例混用**（3/6 候选；「」与弯引号并存）
   组装层 `_quote` 只包裹裸句、不归一已带弯引号的行。修复 = assemble.py 确定性归一化。
4. **场景锚定漂移 / 凭空人物**（vick/c2 major：侍者/仆人/伙计；柜台戏漂成客厅戏）
   分拍 / end prompt 只带契约+局面，不带"在场人物/物理空间"锚定事实。
   修复 = beat/end user prompt 注入 character_state 与 scene anchor 行。
5. **choice 节点旁白元叙述**（vick/c2 整段 major；whitcroft/c1 一句 minor）
   "再多一句…再硬一步…"类替玩家总结选择结构。修复 = pass2 prompt 加一条白描禁则。
6. **跨分支信息近原文复制**（vick/c2 major；vick/c1 / whitcroft 轻度）
   保底线索按 spec 必须各路径可得，但措辞应变化、完整度应分层；vick/c2 未兑现声明的残缺化。
   与 1 同根（分支功能重合），拓扑/骨架层一并治。
7. **AP 程序化检测误报型态确认**（复核副产品）
   - AP-7 三种误报型 ✅ **已修**（2026-06-10 作者明示授权 validator 改动，本分支落地 + 测试）：
     ① 引语归属「…」她说，「…」；② "说话/讲话"物理描写；③ 引号内对白被扫
     （组装后 narration 含 NPC 引号对白）——detect_ap7 跳过引号 span + 豁免集扩 ，/话。
   - AP-8 "先 X。"误报型**保留不动**：豁免"先"前缀会丢真阳性（canonical 反例
     "先追问赌债…"正以"先"开头），留给 LLM-as-judge 精确确认（原计划）。
   - AP-1~6 / AP-9 执行层仍归 LLM-as-judge（作者拍板不扩规则集）。
