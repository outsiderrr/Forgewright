# D3 避免晦涩（Grice manner-1, avoid obscurity）v0.1.1

> talkstyle-skill v0.1 第 3 维度。codex review 第 1 轮后修订版。

## D3.1 精确定义

**D3 避免晦涩**：句子字面意义应能被听者用"普通现代汉语阅读能力"直接读懂，不需要查词典、识别古汉语用法、或具备专业领域知识。

D1 已经管"字面 = 意图"；D3 管"字面本身别太难"。

**学术锚点**：Grice 合作原则 · 方式准则之一（avoid obscurity of expression）。

**注（明确范围）**：v0.1 D3 **不处理** "角色身份相关的高 register 词"（如颔首 / 凛然 / 释怀 / 啜饮）—— 这些词在 CC-CEDICT 有标准义项、普通现代读者能识别，只是书面色彩较重，应该 pass D3。这类**character-bound register 装饰问题归 v0.3 register matching**。D3 v0.1 只抓真正晦涩的字 / 句。

## D3.2 禁止 4 类

### 类别 1：生僻字 / 罕见字

**定义**：超出通用字表（《现代汉语常用字表》3500 字）范围的字；或字虽常见但当前用法在 CC-CEDICT 无收录、属于古义 / 极低频义。

**判定信号**：单字未列入常用字表；字虽常见但当前用法日常使用率接近零。

| 反例 | 正例 |
|---|---|
| "他**彳亍**着走过来。" | "他**慢吞吞**走过来。" |
| "他**翕动**着嘴唇。" | "他**动了动**嘴唇。" |
| "他**囅然**一笑。" | "他**笑了一下**。" |
| "他**戛然**而止。" | "他**突然**停住了。" |

注：反例中的字在 CC-CEDICT 都收录有标准义项（D1 角度 pass），但日常使用率极低，命中 D3。

### 类别 2：古汉语 / 文言用语

**定义**：现代汉语日常使用频率接近零的文言虚词、句式、双音节词。

**判定信号**：使用 之 / 乎 / 者 / 也 / 兮 / 哉 / 矣 等文言虚词；否定式"弗""毋""勿"；判断式"乃是""即为""乃"；双音节文言"是以""然则""焉能""孰知""遑论"等。

| 反例 | 正例 |
|---|---|
| "**弗能**也。" | "**做不到**。" |
| "**是以**他不来。" | "**所以**他不来。" |
| "**乃是**此人。" | "**就是**这个人。" |
| "**焉能**如此？" | "**怎么能**这样？" |

**例外**：角色明确是古风 / 学者 / 江湖角色设定 → v0.3。v0.1 一律 fail。

### 类别 3：专业术语 / 行业 jargon / 缩写 / 外文 / 黑话（无对应解释）

**定义**：行业、学科、技术领域内部术语、未解释的外语词 / 缩写 / 圈层黑话 / 专名型术语，对外部听者无可理解性。

**包含（codex review 修订扩展）**：

- 哲学 / 法律 / 医学 / 技术 / 学术专门术语
- 商务 / 管理缩写（KPI / OKR / ROI / KOL）
- 心理学 / 健康缩写（PTSD / ADHD / OCD）
- 游戏 / 二次元 / 互联网圈层（NPC / RPG / SAN 值 / lore / meta / callback）
- 外语词夹杂（"做个 review" / "follow up 一下"）
- 行业暗语 / 专名型术语

**判定信号**：使用上述术语 / 缩写 / 外语词 / 黑话，且**未紧跟现代汉语解释**。

| 反例 | 正例（含术语 + 解释，符合 D3.4 边界例外）|
|---|---|
| "他的**此在**已被**敞开**。" | "他**活在当下**了。" |
| "**PEP 8** 不允许这么写。" | "**PEP 8——Python 的代码风格规范**——不让这么写。" |
| "**心室颤动**了。" | "**心室颤动了，就是心跳乱到要命。**" |
| "我得**follow up** 这个项目的 **KPI**。" | "我得**跟进这个项目的关键指标**。" |
| "他**SAN 值崩了**。" | "他**精神崩了**。" |

**例外**：紧接现代汉语解释的专业词允许；专业人士对专业人士说专业话 → v0.3 register 处理，v0.1 一律 fail。

### 类别 4：长嵌套句 / 难解句

**定义**：单句过长 / 多层嵌套从句，听者难以一遍听懂。

**判定信号**：句长 > 30 字（不含标点）；嵌套连接词（之所以 / 是因为 / 而那是因为）；≥3 层修饰套层。

| 反例 | 正例 |
|---|---|
| "之所以他不来，是因为昨天晚上发生了一件让他感觉到他不应该来的事情。" | "**他昨晚出事了。不来了。**" |
| "这是他从他姐姐那里借的他妈妈送给他姐姐的那本书。" | "**这本书是他妈给他姐的。他从他姐那借来的。**" |

## D3.3 判定规则（含触发词表前置扫描——codex review 修订）

**codex review 修订**：D3 不只依赖 LLM 直觉，而是**先用客观触发词表扫描，再让 LLM 判定 fail / pass**。这样把"3500 字判定 / 古汉语判定 / 缩写识别"等本来 LLM 直觉不稳的事 anchored 到客观规则。

```
Step 1【触发词表扫描】（客观，无 LLM 主观）

扫描句中是否有：
a) 字未列入《现代汉语常用字表》3500 字（GB2312 一级字符集）
b) 文言虚词触发：之 / 乎 / 者 / 也 / 兮 / 哉 / 矣 / 弗 / 毋 / 勿
   / 焉 / 孰 / 遑 / 然则 / 是以 / 焉能 / 孰知 / 乃是 / 即为 等
c) 缩写型 token：≥2 个大写字母连写（KPI / OKR / PTSD / NPC / OCD 等）
d) 外语词 token：拉丁字母词且非中英混排惯用如 P2P / B2B 等已词典化
e) 句长 > 30 字未断句
f) 嵌套连接词：之所以 / 是因为 + 而那是因为 多层嵌套

命中任一 → 进 Step 2
均无 → pass D3

Step 2【LLM 判定】（命中后由 LLM 决定 fail 还是 pass）

- 触发字 / 词是否日常使用率高？是 → pass
- 触发词后紧跟现代汉语解释（句中显式给出术语定义）？是 → pass
- 长句是否真嵌套（≥3 层 / 中心词修饰跨越多分句）？是 → fail
- 否则 → fail D3
```

**严格 fail 的理由**：D3 的晦涩用法永远不承重信息——一定能换成更通用的表达。

## D3.4 边界

**允许（pass D3）**：

- 字典通用义项内的标准用法（即使略书面，如**颔首 / 凛然 / 释怀 / 啜饮 / 莞尔** —— 这些是 v0.3 处理）
- 字典收录但日常使用率高的字
- 必要技术词 + 紧跟现代汉语解释（"PEP 8——Python 代码风格规范"则 pass；"心室颤动了，就是心跳乱到要命"则 pass）

**严格 fail**：

- 哪怕 LLM 觉得"显得有学问"，v0.1 一律砍
- 字典里有但古汉语 → fail
- 不可避免的专业词 / 缩写 / 外语词 / 黑话 → 必须紧跟现代汉语解释才能用

## D3.5 prompt 片段

### 生成端

```
[D3 · 避免晦涩]
让句子能被普通现代汉语读者一遍读懂。

禁止：
- 生僻字 / 罕见字（常用 3500 字表外）
- 古汉语 / 文言虚词（之乎者也 / 弗 / 是以 / 乃是 / 焉能等）
- 专业术语 / 行业 jargon / 缩写（KPI / OKR / NPC / SAN 值等）
  / 外语词夹杂（follow up / review）/ 圈层黑话
  除非紧跟现代汉语解释
- 长嵌套句（> 30 字未断 / ≥3 层从句）

允许：
- 字典通用义项内的标准用法（含略书面但常见的词，
  如颔首 / 凛然——这是 v0.3 处理）
- 必要技术词 + 紧跟现代汉语解释
  例："心室颤动了，就是心跳乱到要命。"
- 短句拆分
```

### Review 端（codex review 修订——强约束 review pipeline）

```
[D3 · 避免晦涩 review]

Step 1【触发词表前置扫描】（客观扫描，先于 LLM 判定）
命中以下任一即进 Step 2：
a) 字未列入《现代汉语常用字表》3500 字
b) 文言虚词触发（之乎者也兮哉矣弗毋勿焉孰遑 /
   然则 / 是以 / 焉能 / 孰知 / 乃是 / 即为）
c) 缩写型 token（≥2 大写字母连写：KPI / OKR / PTSD / NPC）
d) 外语词 token（拉丁字母词且非已词典化）
e) 句长 > 30 字未断句
f) 嵌套连接词（之所以...是因为...而那是因为...）

Step 2【LLM 判定】（命中后由 LLM 决定）
- 触发字 / 词日常使用率高？→ pass
- 紧跟现代汉语解释？→ pass
- 长句真嵌套（≥3 层）？→ fail
- 否则 → fail

输出：[D3: pass] 或 [D3: fail (命中类别 + 引用具体短语)]
```

## D3.6 跟其他维度的关系

- **D1**：D3 的"晦涩字"通常字面 = 意图——不命中 D1 但命中 D3
- **D2 拒绝装饰**：D2 反复跨句 / 形式装饰；D3 难懂 / 长嵌套；不重叠
- **D4 避免歧义**：D3 的长嵌套句常顺带触发 D4
- **D5 简明**：D3 的长嵌套句必然 D5 fail
- **D6 有序**：嵌套句也可能 D6 fail
- **v0.3**：character-身份相关的 register 词（颔首 / 凛然 / 释怀）—— D3 不抓，v0.3 抓
