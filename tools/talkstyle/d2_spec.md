# D2 拒绝装饰（formal patterning rejection）v0.1.1

> talkstyle-skill v0.1 第 2 维度。codex review 第 1 轮后修订版。

## D2.1 精确定义

**D2 拒绝装饰**：句子的结构形式只服务于信息传递，**不为美感重排**。

任何让句子"听起来工整 / 有节奏 / 有对应 / 押脚"的形式特征都禁。字面意义跟意图意义可以一致（已被 D1 管），但**形式上的工整本身是 v0.1 不接受的**。

**学术锚点**：Leech & Short《Style in Fiction》中 **figures of speech / formal patterning** 包含的**句法、音系、词汇三层形式装饰**——parallelism / chiasmus / antithesis / rhyme / repeated formulae 等。

## D2.2 禁止 7 类（含 chiasmus、判定信号、限定）

### 类别 1：对称结构（对仗 / 交错配列 / 回环）

两个分句结构对应，或前后倒置对应（AB / BA chiasmus）。

**判定信号**：分句间存在主谓宾对位、词性对位、语义位置对位；或前句"X 动作 Y"+ 后句"Y 动作 X"的倒置。

| 反例 | 正例 |
|---|---|
| "墙这边听不见，门那边听得真。" | "墙这边听不清。后厨门关不严。" |
| "不是门关住了他，是他关住了门。" | "他走不出去——门从外面锁了。" |

### 类别 2：一虚一实结构（前句字面 + 后句抽象配对）

**判定点是"字面分句 + 抽象分句"的工整配对形式，不是抽象词义本身**——抽象词独立出现不命中。

**判定信号**：第一分句描述具体物 / 动作 / 物理事实；第二分句换成抽象概念但保持跟第一分句相同的句式 / 字数 / 否定结构。

| 反例 | 正例 |
|---|---|
| "这名字在这儿不买酒也不买平安。" | "这名字在我们这从来不带好消息。" |

### 类别 3：排比（≥3 个同结构分句连用）

**判定信号**：三个或更多分句采用相同句法结构、主语角色或动词模板。

| 反例 | 正例 |
|---|---|
| "他查过柜台，她查过后门，我查过账本。" | "柜台、后门、账本——我们三个分头查过了。" |

### 类别 4：押韵（句末同韵脚）

**判定信号**：分句结尾的韵母（普通话拼音）相同或近似；非偶然同韵的 ≥2 个分句。

| 反例 | 正例 |
|---|---|
| "钱不到位，事不到位。" | "钱没给够，事就办不成。" |

### 类别 5：字数对齐 + 结构对应

**判定信号**：前后分句字数相等或接近，**且**句法槽位 / 词性 / 语义角色明显对应。**单纯字数接近不算**——必须伴随结构对应才命中。

| 反例 | 正例 |
|---|---|
| "他说东，我说西。" | "他说要走东边。我没按他说的走。" |

### 类别 6：反复（同词 / 同句多次重复以强调）

**判定信号**：同一个词或短语在邻近 1-3 句内重复 ≥2 次以强化语气，**且重复不来自情境需要**（听错 / 口吃 / 纠正 / 复述指令等"交互修复"）。

| 反例 | 正例 |
|---|---|
| "我累了。真的累了。太累了。" | "我累了。" |

**例外（不算反复，pass）**：

- 复述指令："你说啥？" "我说，**他不在**。"
- 口吃："你——你确定？"
- 纠正："不是'后门'——是**'后山'**。"

### 类别 7：成语 / 套话堆叠

**判定信号**：两个以上成语、熟语或明显四字格套话连续出现。**承认是 LLM 模式识别**（"这看起来是固定四字格"），不假装需要精确词典。

| 反例 | 正例 |
|---|---|
| "他狡兔三窟，藏身有方，韬光养晦。" | "他有好几个藏身的地方。" |

## D2.3 判定规则

```
Q1【模式扫描】
   句中有无 §D2.2 七类之一？
   - 无 → pass D2
   - 有 → fail D2（命中即 fail，不做替换测试）
   - 多类命中 → multi-class fail，按优先级标主类
```

**优先级**（多类命中时主类报告顺序）：

```
类别 1（对称结构）> 类别 2（一虚一实）> 类别 3（排比）
> 类别 5（字数对齐+结构对应）> 类别 4（押韵）
> 类别 6（反复）> 类别 7（成语堆叠）
```

**只一步直接 fail 的理由**：D1 有"承重 figurative"概念（活比喻有时压缩多个含义，删了真损失信息），所以保留 flag 兜底。D2 的装饰**永远不承重信息**——结构对仗 / 押韵 / 字数对齐 本质上就是"形式重排"，删了之后信息一定能完整传达。所以严格 fail，不留 flag。

## D2.4 边界条件

**严格 fail 的情形**：

- **结构对应即算命中**：即使两个分句信息独立，只要结构、词性、语义位置同时对应，也算 D2 命中。例如"我去前厅。你去后院。"按 D2 严格判定 **fail**（主语 + 去 + 方位的同构对应）
- 不管 LLM 多自信"这样更地道"——v0.1 一律砍
- 不管中文文学传统多爱对仗——v0.1 立场就是"反 AI 写作模式"，要先削掉这个

**允许的例外**：

- **真实交互修复**：听错 / 口吃 / 纠正 / 复述指令等情境驱动的重复（见类别 6 例外）
- **独立信息且结构不对应**：例如"我去前厅。**你守着后院门，别让人出来**。" ← 后句信息量明显多 + 句长结构不对应，不算装饰

## D2.5 可植入 prompt 片段

### 生成端

```
[D2 · 拒绝装饰]
不要把句子重排成"工整 / 有节奏 / 有对应"的形式。
禁止：
- 对称结构（对仗 / 交错配列 / 回环——分句结构对应或 AB/BA 倒置）
- 一虚一实（前句字面，后句抽象，工整配对）
- 排比（≥3 个同结构分句连用）
- 押韵（句末同韵脚）
- 字数对齐 + 结构对应（不是单纯字数接近）
- 反复（同词 / 同句重复以加强语气）
  例外：必要的听错、口吃、纠正、复述指令等交互修复不算
- 成语 / 套话堆叠（≥2 个四字格连用）

让句子按信息内容自然产生。不为美感重排。
```

### Review 端

```
[D2 · 拒绝装饰 review]
对每句对白扫描 7 个装饰子模式：
1. 对称结构：分句间主谓宾对位 / 词性对位 / AB-BA 倒置？
2. 一虚一实：前句字面 + 后句抽象，工整配对？
3. 排比：≥3 个同结构分句？
4. 押韵：句末同韵脚？
5. 字数对齐 + 结构对应：字数相等/接近 + 句法槽位/词性/语义角色明显对应？
6. 反复：同词/同句邻近重复 ≥2 次以强调，且非"交互修复"
   （听错/口吃/纠正/复述指令）？
   若输入无上下文，强调性重复默认 fail
7. 成语 / 套话堆叠：≥2 个四字格 / 熟语连续出现？

任一命中 → fail D2（不做替换测试，严格立场）
多类命中 → multi-class fail
优先级排序：1 > 2 > 3 > 5 > 4 > 6 > 7
无字典查询需求；纯 LLM 模式识别。

输出格式：
[D2: pass]
或
[D2: fail (主类 + 其他命中类别, 引用具体短语)]
```

## D2.6 跟其他维度的关系

- **D1**：D2 反例可能命中 D1（如"墙比夜更厚"是活比喻 D1 fail + 对仗 D2 fail），两边都打，**取合集**，不去重
- **D3 避免晦涩 / D4 避免歧义**：装饰句通常清晰、不晦涩、不歧义——D2 命中跟 D3/D4 几乎不重叠
- **D5 简明**：装饰句通常比直说版略长——D2 命中常顺带 D5 fail
- **D6 有序**：D2 跟 D6 几乎不重叠
